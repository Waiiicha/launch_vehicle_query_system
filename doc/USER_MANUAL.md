# 全球运载火箭信息查询系统 - 用户手册

## 1. 系统概览
本系统是一个高性能的 Web 端火箭情报查询平台，采用了科幻风格的 UI 设计，旨在直观展示全球主流发射载具的技术指标。

## 2. 核心功能操作

### 2.1 搜索与发现
- 在左侧控制面板的 **“搜索型号/代号”** 输入框中输入关键词（如 "CZ"、"SpaceX"），系统将实时过滤右侧卡片。
- 卡片底部显示该火箭的 **LEO 运力** 和 **起飞推力** 进度条，方便横向对比。

### 2.2 高级维度查询
- **运力筛选**：拖动 LEO 运力滑块，可寻找从微纳卫星发射器到超重型火箭的特定型号。
- **推力筛选**：过滤具备强劲动力输出的重型载具。
- **阵营切换**：勾选 CN (中国) 或 US (美国) 快速切换不同国家的火箭谱系。

### 2.3 查看全息数据
- 点击卡片底部的 **“查看全息数据”** 按钮，系统将弹出详细面板，展示包括一级发动机型号、燃料组元以及深空探测能力在内的所有情报。

## 3. 数据维护 (管理员)
如果您需要更新基础数据：
1. 编辑 `doc/20251225-运载火箭信息表-v2.md` 文件中的 Markdown 表格。
2. 在服务器端运行 `npm run seed` 命令，系统将自动解析文档并更新数据库。
